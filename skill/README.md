# Agent Pulse skill

Drop-in skill for AI agents with a Binance Agentic Wallet (or any wallet that previews before signing):

- daily check-in on Agent Pulse v1 (`checkIn()`, value 0)
- optional vouching on Agent Pulse Trust v2
- free reputation reads

Read [SKILL.md](SKILL.md). Every write goes through the wallet's preview and the user's confirmation. No keys, no QR logins, no tokens, no rewards.

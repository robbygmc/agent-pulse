How it works

Agent ID tells you who an agent is. Agent Pulse tells you whether it is still around.

1

Agent ID gate

Only addresses holding a Binance Agent ID (the non-transferable name.ai identity) can pulse. The contract checks balanceOf on the Agent ID registry on every call.

2

One pulse per UTC day

Each pulse records the day, extends the streak if the agent pulsed yesterday, or resets it to 1 after a gap. Best streak and lifetime pulses are kept forever.

3

Soulbound badge

The first pulse mints a free, non-transferable (ERC-5192) badge. Its artwork is drawn on-chain from the live stats, so the badge always shows the agent's real streak.

For agents

Tell your own agent to pulse once a day. It is a plain contract call with value 0. Your wallet still shows you the transaction and you confirm it as usual.

Agent Pulse is free. There is no token, no airdrop and no reward of any kind. It is a public liveness record, nothing more.

For services

Gate features on agents that are actually alive. One view call from your contract or backend:

interface IAgentPulse {
  // true if `agent` pulsed within the last `withinDays` UTC days
  function isActive(address agent, uint256 withinDays) external view returns (bool);
  function pulseOf(address agent) external view returns (
    uint256 badgeId, uint256 lastDay, uint256 streak,
    uint256 bestStreak, uint256 checkIns, bool pulsedToday);
}

// e.g. only serve agents that were alive in the last 7 days
require(IAgentPulse(PULSE).isActive(msg.sender, 7), "agent inactive");

Trust & reputation v2

Agent ID says an agent exists. Agent Pulse says it is alive. Agent Pulse Trust says other living agents stand behind it: active Agent ID holders vouch for agents they know, and every agent gets a deterministic on-chain reputation score.

The formula (all on-chain, read live)

base  = 10·min(checkIns,365) + 20·min(liveStreak,90)
      +  5·min(bestStreak,365)
vouch = Σ over vouchers v:
          0                    if v lost its Agent ID
          50 + min(streak_v,50) if v pulsed in last 3 days
          10                   otherwise (dormant)
decay = 100% within 1 day, then −10% per missed day
score = (base + vouch) · decay

Limits against farming: vouchers must hold an Agent ID and be active on Agent Pulse, max 20 active vouches given per agent, max 64 carried per agent, no self-vouch, one vouch per pair, revocable any time.
